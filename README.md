# PawConnect - Meetup for Pet-Friendly Locations

This is a prototype landing page for a platform that helps pet owners find and meet at pet-friendly locations.

## Features

- **Responsive Design**: Works on mobile, tablet, and desktop devices
- **Modern UI**: Clean, friendly, and engaging design
- **Interactive Elements**: Testimonial slider, animated sections
- **Easy Navigation**: Smooth scrolling to sections

## Structure

- **Hero Section**: Main call-to-action and value proposition
- **How It Works**: Simple 3-step process explanation
- **Featured Locations**: Example pet-friendly places with details
- **Benefits**: Why users should join the platform
- **Testimonials**: Feedback from pet owners
- **Email Signup**: Form to join the waitlist
- **Footer**: Links and copyright information

## Technical Information

- Built with vanilla HTML, CSS, and JavaScript
- No external frameworks or libraries used
- All images are from free sources (Unsplash, randomuser.me)
- Uses Font Awesome for icons

## How to Run

Simply open the `index.html` file in any modern web browser.
